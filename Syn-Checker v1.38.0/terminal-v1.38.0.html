A reference for what a complete, working configuration usually includes — not something Free Practice checks or grades. Use it as a "did I forget anything?" guide while you practice freely.

Tip: sketch the topology with every IP address labeled before typing a single command — this one habit prevents most mid-lab confusion.

Phase 2 — Router Base Configuration
  • hostname <name>
  • enable secret <password>
  • service password-encryption
  • banner motd # ... #
  • line console 0 → password / login / logging synchronous / exec-timeout
  • line vty 0 4 (or full range) → login local (or login + password)
  • transport input ssh (and/or telnet)
  • If using SSH: ip domain-name, crypto key generate rsa, username <user> secret <pass>
  • Configure each interface: ip address, no shutdown, description
  • Configure routing: static routes or dynamic routing protocol
  • copy running-config startup-config
Phase 3 — Switch Base Configuration
  • hostname <name>
  • enable secret <password>
  • Management SVI (interface vlan 1 or mgmt VLAN): ip address, no shutdown
  • ip default-gateway <gateway IP>
  • Console / VTY lines configured (same as router)
  • Create VLANs: vlan <id> / name <name>
  • Assign access ports: switchport mode access / switchport access vlan <id>
  • Configure trunk ports: switchport mode trunk / switchport trunk allowed vlan
  • Port security configured (if required by the lab)
  • copy running-config startup-config
Phase 4 — Verification (Don't Skip This)
  • show ip interface brief — interfaces up/up with correct IPs
  • show vlan brief — VLAN assignments correct
  • show interfaces trunk — trunks actually trunking
  • show cdp neighbors — physical connections match the diagram
  • Ping directly connected devices first, then end-to-end
  • show running-config — visual final check for missed lines

Common mistake: configuring everything first and testing only at the very end. Test connectivity after each device (or major step) instead — it turns troubleshooting from a guessing game into a quick isolation.

! (choose 1024 or higher when prompted)

!
