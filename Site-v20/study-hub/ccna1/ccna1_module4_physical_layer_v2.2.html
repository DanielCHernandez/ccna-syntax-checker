4.1Purpose of the Physical Layer▾

4.1.1 Physical Connections — Wired and Wireless

Before any network communications can occur, a physical connection to a local network must be established. Two types:

TypeDescriptionRequires
WiredData transmitted through a physical cableCable + Ethernet NIC
WirelessData transmitted using radio wavesWLAN NIC + Wireless AP or router

Wireless router components: wireless antennas (may be embedded) · Ethernet switch ports · internet port

Network Interface Cards (NICs):

  • Ethernet NIC — used for wired connections
  • WLAN NIC — used for wireless connections
  • End devices may include one or both (e.g., a network printer may have only an Ethernet NIC; a smartphone may have only a WLAN NIC)

4.1.2 The Physical Layer Function

The OSI physical layer (Layer 1) is at the bottom of the OSI stack. It is part of the Network Access layer in the TCP/IP model.

DirectionWhat the Physical Layer Does
SendingAccepts a complete frame from the Data Link layer → encodes it as a series of electrical, optical, or radio signals → transmits those signals onto the local media one bit at a time
ReceivingRetrieves individual signals from the media → restores them to their bit representations → passes the complete frame back up to the Data Link layer
💡
The physical layer doesn't interpret frame content — it only handles the physical transmission of bits. The entire frame comes from above (Data Link layer) and is converted to signals, then converted back from signals to bits at the destination.

4.2.2 Three Functional Areas of Physical Layer Standards

AreaDescription
Physical ComponentsElectronic hardware: NICs, interfaces, connectors, cable materials, cable designs, port types
EncodingMethod of converting a stream of data bits into a recognizable pattern/code
SignalingHow "1" and "0" are represented as actual signals on the medium

4.2.3 Encoding

Encoding (line encoding) = converting a stream of data bits into a predefined "code" recognizable by both sender and receiver. Similar to Morse code — a series of dots and dashes encode letters.

Encoding SchemeUsed InHow It Works
Manchester encoding10BASE-T (10 Mbps Ethernet)0 bit = high-to-low voltage transition · 1 bit = low-to-high voltage transition · Transition occurs at the middle of each bit period
4B/5B100BASE-TX (100 Mbps)4 data bits mapped to 5-bit code groups to ensure enough transitions for clock synchronization
8B/10B1000BASE-T (1 Gbps)8 data bits mapped to 10-bit code groups; more complex for higher speeds

4.2.4 Signaling — How 1s and 0s Travel

Signaling = the method used to represent bits as physical signals on the medium. The physical layer must generate the appropriate signal type for each medium:

⚡
Copper Cable
Electrical pulses (voltage changes)
💡
Fiber-Optic

📡
Wireless
Microwave / radio transmissions

4.2.5 Bandwidth — Definition and Units

Bandwidth = the capacity at which a medium can carry data. Measures how many bits can flow from one place to another per unit time.

⚠️
Bandwidth ≠ speed of bit travel. In both 10 Mbps and 100 Mbps Ethernet, bits travel at the same speed (speed of electricity). The difference is how many bits per second are transmitted. Bandwidth = capacity, not velocity.
UnitAbbreviationEquivalence
Bits per secondbpsFundamental unit
Kilobits per secondKbps1,000 bps = 10³ bps
Megabits per secondMbps1,000,000 bps = 10⁶ bps
Gigabits per secondGbps1,000,000,000 bps = 10⁹ bps
Terabits per secondTbps1,000,000,000,000 bps = 10¹² bps

Practical bandwidth depends on: properties of the physical media + technologies chosen for signaling and detecting network signals.

4.2.6 Latency, Throughput, and Goodput

Bandwidth — Maximum theoretical capacity of the medium ▶ Highest
Throughput — Actual bits transferred per second (usually lower than bandwidth) ▶ Middle
Goodput — Usable data only (throughput minus overhead) ▶ Lowest
TermDefinitionWhat Reduces It
LatencyTotal time (including all delays) for data to travel from one point to another. Affects throughput.Number of network devices; queuing delay; propagation delay; processing delay
ThroughputActual measure of bits transferred across media over a given periodTraffic amount and type; latency from devices; congestion
GoodputUsable data transferred per unit time = Throughput minus overheadSession setup overhead; acknowledgments; encapsulation headers; retransmissions
🎯 ORDER — EXAM KEY
Bandwidth ≥ Throughput ≥ Goodput (always, without exception)
Throughput is always ≤ bandwidth (traffic, latency, device processing reduce it).
Goodput is always ≤ throughput (session setup, ACKs, encapsulation, retransmissions subtract from usable data).
Even in perfect conditions: Goodput < Throughput < Bandwidth.
4.3Copper Cabling▾

4.3.1 Copper Characteristics

Why copper is popular: inexpensive · easy to install · low resistance to electrical current

Limitations: distance (attenuation) · signal interference

Attenuation = signal weakening over distance. All copper media must follow strict distance limits per standard.

Two interference sources:

📻 EMI / RFI
Electromagnetic Interference / Radio Frequency Interference
External source. Comes from: fluorescent lights · electric motors · radio waves · other electromagnetic devices.
Fix: metallic shielding (used in STP) + proper grounding
🔀 Crosstalk
Between adjacent wires
Electric/magnetic field from one wire couples into an adjacent wire. Can cause hearing part of another voice call in phone circuits.
Fix: twisted wire pairs (cancellation effect)

Additional mitigation techniques:

  • Select cable type/category suited to the environment
  • Design infrastructure to avoid known interference sources
  • Use proper cable handling and termination techniques

4.3.2–4.3.5 Three Types of Copper Cabling

🔶 UTP — Unshielded Twisted-Pair
Most common networking media. Terminated with RJ-45 connectors. 4 color-coded twisted pairs in flexible plastic sheath.
  • Outer jacket — physical damage protection
  • Twisted pairs — signal interference protection via cancellation
  • Color-coded insulation — electrically isolates wires + identifies each pair
Relies entirely on cancellation (no shielding). Most widely used in LAN environments.
🔷 STP — Shielded Twisted-Pair
Better noise protection than UTP. More expensive and harder to install. Also uses RJ-45 (with special shielded terminations).
  • Combines shielding (against EMI/RFI) + twisting (against crosstalk)
  • Structure: outer jacket → overall metallic braid/foil → 4 individual foil-shielded wire pairs
⚠️ Critical: If improperly grounded, shield acts as an antenna — picks up MORE unwanted signals. Grounding is essential for STP to work correctly.
⚫ Coaxial Cable (Coax)
Named because two conductors share the same axis. Structure (inside out): copper conductor → plastic insulation → woven copper braid/foil → outer jacket. Connectors: BNC, N type, F type
  • Not used in modern Ethernet
  • Used for: wireless antenna connections (carries RF energy between antenna and radio equipment)
  • Used for: inside customer premises in cable internet installations
4.4UTP Cabling▾

4.4.1 How UTP Counters Interference — No Shielding Needed

UTP uses two techniques instead of shielding:

  1. Cancellation — pairing wires in a circuit; opposing magnetic fields cancel each other AND cancel outside EMI/RFI signals. The closer together the two wires, the more effective the cancellation.
  2. Varying the number of twists per pair — each color pair twisted a different number of times per meter; more twists = better cancellation. Must meet precise TIA/EIA specifications.
💡
UTP "self-shields" through the physics of cancellation — no metal shielding required. This keeps UTP flexible, inexpensive, and easy to install — and it works effectively for most LAN environments.

4.4.2 UTP Categories, Standards, and Connectors

Standards: TIA/EIA-568 = commercial cabling standard (defines types, lengths, connectors, termination, testing). IEEE = defines electrical characteristics and UTP categories by performance.

Cat 3Voice
Originally voice; later used for data. Now obsolete for networking.
Cat 5100 Mbps
Used in 100BASE-TX Fast Ethernet
Cat 5e1 Gbps
⚠️ Minimum acceptable for new installations
Cat 610 Gbps
✅ Recommended for new building installations · Has added separator between each wire pair
Cat 6a10 Gbps
Extended range vs Cat 6
Cat 840 Gbps
Newest category; data center use

Connector: RJ-45 — male plug crimped at end of cable / female socket on device or wall outlet. Improper termination is a source of physical layer performance degradation. Untwist wires only to the extent necessary to attach the connector.

4.4.3 Straight-through, Crossover, and Rollover Cables

T568A and T568B wiring standards define pin assignments (pinouts) for RJ-45 connectors. The key difference: orange pair and green pair swap positions between A and B.

➡️ Ethernet Straight-through
Both ends same standard (T568A–T568A or T568B–T568B)
Use: Host → Switch · Switch → Router
Most common cable type in networking.
🔀 Ethernet Crossover
Different standards on each end (one T568A, one T568B)
Use: Switch–Switch · Router–Router · Host–Host
⚠️ Now considered legacy because NICs use auto-MDIX to automatically detect and correct cable type.
↩️ Rollover (Cisco Proprietary)
Cisco proprietary wiring
Use: Workstation serial port → Router or switch console port
Used for out-of-band management (CLI access). Uses DB-9 or USB adapter at workstation end.
🚨
Using the wrong cable type does NOT damage devices — but it PREVENTS connectivity. Checking cable type should always be the FIRST troubleshooting step when two devices fail to communicate.
4.5Fiber-Optic Cabling▾

4.5.1 Fiber-Optic Properties

  • Transmits data as light pulses through flexible, extremely thin transparent strands of very pure glass (about the size of a human hair)
  • Acts as a waveguide ("light pipe") — transmits light between two ends with minimal signal loss
  • Longer distances and higher bandwidths than any other networking media
  • Less attenuation than copper
  • Completely immune to EMI and RFI — glass conducts no electricity, so no electromagnetic interference is possible
  • More expensive than copper; requires more skill to install and terminate

4.5.2 SMF vs MMF — Two Types of Fiber Media

🔵 SMF — Single-Mode Fiber
  • Very small core
  • Uses expensive laser light source
  • Single ray travels straight through
  • Less dispersion (signal stays focused)
  • Distance: hundreds of km
  • Up to 100 Gbps
  • Jacket color: Yellow
  • Use: long-haul telephony, cable TV, transoceanic
🟢 MMF — Multimode Fiber
  • Larger core
  • Uses low-cost LED light source
  • Light enters at multiple angles (bouncing)
  • More dispersion → shorter max distance
  • Distance: up to 550 meters
  • Up to 10 Gbps
  • Jacket color: Orange (or aqua)
  • Use: LAN backbone, enterprise, buildings
💡
Dispersion = spreading out of a light pulse over time → increased signal loss. MMF has greater dispersion than SMF → shorter maximum distance. This is why MMF is limited to ~550m while SMF can run hundreds of kilometers.

4.5.3 Four Fiber Industry Uses

  1. Enterprise Networks — backbone cabling and interconnecting infrastructure devices (most relevant to CCNA)
  2. FTTH (Fiber-to-the-Home) — provides always-on broadband to homes and small businesses
  3. Long-Haul Networks — service providers connecting countries and cities
  4. Submarine Cable Networks — connecting continents under oceans; must survive harsh undersea environments

In enterprise environments: fiber primarily used as backbone cabling for high-traffic point-to-point connections between data distribution facilities and for interconnecting campus buildings.

4.5.4 Fiber-Optic Connectors

ST — Straight-Tip
One of the first fiber connector types. Bayonet-style twist-on/twist-off mechanism. Named for its round shape.
SC — Subscriber Connector
"Square connector" or "standard connector." Push-pull mechanism for positive insertion. Widely adopted for LAN and WAN. Works with both SMF and MMF.
LC — Lucent Connector (Simplex)
"Little connector" or "local connector." Smaller version of SC. Rapidly growing in popularity due to smaller size.
Duplex Multimode LC
LC connector accepting both TX and RX fibers in a single connector. Used where full-duplex on one connector is needed.
💡
SFP (Small Form-factor Pluggable) transceivers are used on some Cisco switches and routers to support fiber-optic connectors. An SFP slides into a slot on the device and provides the fiber interface.

Fiber patch cord jacket colors: Yellow = SMF · Orange (or aqua) = MMF

4.6Wireless Media▾

4.6.1 Wireless Properties and Limitations

Wireless media carry electromagnetic signals representing binary data using radio or microwave frequencies. Provides the greatest mobility of all media types.

Four limitations of wireless:

LimitationDescription
Coverage areaBuilding construction materials, structures, and local terrain limit effective coverage
InterferenceHousehold cordless phones, fluorescent lights, microwave ovens, and other wireless devices can disrupt signals
SecurityNo physical strand required — unauthorized devices can potentially intercept transmissions; major security concern for wireless network administration
Shared medium (half-duplex)WLANs operate in half-duplex — only one device sends or receives at a time; many simultaneous users = reduced bandwidth per user
💡
Copper and fiber remain the most popular physical layer media for intermediary network devices (routers, switches) even as wireless grows for end-user connections.

4.6.2 Four Wireless Standards

📶 Wi-Fi — IEEE 802.11 (WLAN)
Wireless LAN technology. Uses CSMA/CA (Carrier Sense Multiple Access/Collision Avoidance) — NIC must listen before transmitting; if channel is busy, NIC waits. Wi-Fi is a trademark of the Wi-Fi Alliance for certified IEEE 802.11 devices.
🔵 Bluetooth — IEEE 802.15 (WPAN)
Wireless Personal Area Network. Uses a device pairing process to communicate. Range: 1–100 meters. Used for personal device connectivity (headphones, keyboards, phones).
📡 WiMAX — IEEE 802.16
Worldwide Interoperability for Microwave Access. Uses point-to-multipoint topology to provide wireless broadband access. Longer range than Wi-Fi.
🌿 Zigbee — IEEE 802.15.4 (IoT)
Low data rate, low power communications. Short range, very long battery life. Used for: industrial environments, IoT applications (wireless light switches, medical device data collection, smart home). Not for general data networking.

4.6.3 Wireless LAN (WLAN) — Required Components

ComponentDescription
Wireless Access Point (AP)Concentrates wireless signals from users and connects to the existing copper-based network infrastructure (Ethernet). Home/small business wireless routers combine router + switch + AP in one device.
Wireless NIC adaptersProvide wireless communication capability to network hosts. May be internal (built-in) or external (USB adapter).
⚠️
Security is a major concern for WLANs. Without a physical cable, any device within range can potentially attempt to join the network. Network administrators must implement strong security policies (WPA3, authentication, encryption) to protect WLANs from unauthorized access.

🎯Common Exam Traps — Module 4▾
❌
Trap 1: The physical layer accepts a complete FRAME from Data Link — not a packet.
The physical layer encodes the frame and transmits it as bits. It does not process the content. At the destination, it converts signals back to bits and passes the frame up to the Data Link layer. Packets live at Layer 3 (Network); Frames live at Layer 2 (Data Link); Bits live at Layer 1 (Physical).
❌
Trap 2: Bandwidth ≠ speed of bit travel. Both 10 Mbps and 100 Mbps Ethernet bits travel at the speed of electricity.
The difference is bits per second — how many bits are packed into each second of transmission. Bandwidth = capacity. Bits always travel at roughly the same speed through a medium regardless of bandwidth rating.
❌
Trap 3: Bandwidth ≥ Throughput ≥ Goodput — always in this order.
Throughput is always lower than bandwidth due to traffic type, latency, and device processing. Goodput is always lower than throughput because it subtracts session setup overhead, acknowledgments, encapsulation, and retransmissions.
❌
Trap 4: Two copper interference sources — EMI/RFI (external, fixed by shielding) and Crosstalk (between wires, fixed by twisting).
EMI/RFI comes from outside the cable (lights, motors, radio). Crosstalk comes from adjacent wire pairs inside the cable. UTP counters crosstalk only (cancellation). STP counters both (shielding + twisting). Know which problem each technique addresses.
❌
Trap 5: STP improperly grounded = acts as an ANTENNA = MORE interference.
The metallic shield in STP must be properly grounded at both ends. If grounding is poor or missing, the shield itself becomes an antenna that collects and amplifies interference — making it perform worse than UTP. Grounding is critical to STP effectiveness.
❌
Trap 6: Coaxial cable is NOT used in modern Ethernet networks.
Coax is used for: (1) connecting antennas to wireless devices (RF energy between antenna and radio) and (2) inside customer premises for cable internet. Don't confuse "coax still exists" with "coax is used in Ethernet." Modern Ethernet uses UTP (or fiber for backbone).
⚠️
Trap 7: Cat 5e = minimum for new installations (1 Gbps). Cat 6 = recommended (10 Gbps). Cat 8 = 40 Gbps.
Cat 5 is only 100 Mbps. Cat 5e is the minimum acceptable for any new installation. Cat 6 has a physical separator between each wire pair and is recommended. Cat 8 is for data center use at 40 Gbps. Never recommend Cat 5 for new installations.
⚠️
Trap 8: Straight-through = both ends SAME standard. Crossover = ends are DIFFERENT standards.
Straight-through: host to switch, switch to router. Crossover: like-to-like (switch-switch, router-router, host-host). Crossover is now legacy due to auto-MDIX. Rollover (Cisco proprietary) = workstation serial to console port only.
⚠️
Trap 9: Wrong cable type does NOT damage devices — but PREVENTS connectivity. Always check cable type first when troubleshooting.
The devices are protected against wrong cable type. The connection simply won't work. This is one of the most common physical layer installation mistakes and should always be the first item checked.
⚠️
Trap 10: SMF = laser + yellow jacket + hundreds of km. MMF = LED + orange jacket + up to 550m.
SMF is for long distances (long-haul, WAN). MMF is for LAN/enterprise (up to 550m). Dispersion is greater in MMF → shorter maximum distance. Mixing SMF and MMF components causes significant signal loss. Know the jacket colors for identifying fiber type.
⚠️
Trap 11: Fiber is completely immune to EMI and RFI — glass carries light, not electricity.
There is no electrical signal in fiber to be disrupted by electromagnetic interference. This makes fiber ideal for high-noise environments, long outdoor runs, and anywhere electrical isolation is required between buildings.
⚠️
Trap 12: WLAN uses CSMA/CA (collision AVOIDANCE) — wired Ethernet uses CSMA/CD (collision DETECTION).
Wireless devices cannot detect collisions while transmitting (the transmitting signal drowns out received signals). They avoid collisions instead by listening before transmitting. CA = avoidance (wireless). CD = detection (wired Ethernet, legacy half-duplex).
⚠️
Trap 13: Wireless is half-duplex — only one device transmits at a time.
This is a fundamental limitation of wireless vs wired switched Ethernet (which can run full-duplex). Many users sharing the same wireless frequency results in reduced per-user bandwidth. This is why enterprise WLANs need careful channel planning and sufficient access points.
⚠️
Trap 14: Zigbee (802.15.4) = IoT/low power — NOT for general networking. WiMAX (802.16) = wireless broadband — NOT Wi-Fi.
802.11 = Wi-Fi (WLAN). 802.15 = Bluetooth (WPAN). 802.16 = WiMAX (wireless broadband, point-to-multipoint). 802.15.4 = Zigbee (IoT, low data rate, long battery life). These four standards appear in IEEE number matching questions.
✅
