1.1Networks Affect our Lives▾

1.1.1 Networks Connect Us

Communication ranks just below food, water, and shelter among human essentials. Through networks, we are more connected than ever before — people share ideas instantly across oceans, news travels worldwide in seconds, and friends play games across continents.

1.1.3 No Boundaries

Networking advancements are among the most significant changes in the world today, reducing the relevance of national borders, geographic distances, and physical limitations. The internet has transformed social, commercial, political, and personal interactions — enabling global communities independent of location or time zone.

The cloud lets us store documents and access them from anywhere, on any device — on a train, in a park, or on a mountaintop.

1.2Network Components▾

1.2.1 Host Roles — Servers and Clients

All computers connected to a network that participate directly in network communication are classified as hosts (also called end devices). Hosts are assigned an IP address — a number that identifies the host and the network to which it is attached.

RoleDescriptionExamples
ServerComputer with software that provides services (web pages, email, files) to other end devices. Each service requires separate server software. One server can serve many clients simultaneously.Web server, email server, file server
ClientA type of host; has software for requesting and displaying information obtained from a server.Web browser (Chrome, Firefox), email client (Outlook)

Common Server Types

Server TypeServer SoftwareClient Software
EmailEmail server softwareMicrosoft Outlook, Thunderbird
WebWeb server softwareChrome, Firefox, Edge
FileFile server softwareWindows File Explorer, Finder

1.2.2 Peer-to-Peer Networks

When one computer acts as both server and client simultaneously, it forms a peer-to-peer (P2P) network. Common in small businesses and homes.

✅ P2P Advantages
  • Easy to set up
  • Less complex
  • Lower cost — no dedicated servers or network devices required
  • Suitable for simple tasks: file sharing, printer sharing
❌ P2P Disadvantages
  • No centralized administration
  • Not as secure
  • Not scalable
  • Devices acting as both client and server → slower performance

1.2.3 End Devices

An end device is either the source or destination of a message transmitted over the network. Each end device has an address to distinguish it from others. Data flows from the source end device toward the destination end device.

💡
End devices are what users interact with directly — PCs, laptops, tablets, smartphones, IP phones, printers, servers. They are the starting and ending points of all network communication.

1.2.4 Intermediary Devices

Intermediary devices connect end devices to the network and connect multiple networks to form an internetwork. They use the destination address + network topology information to determine the path for messages.

Functions of intermediary devices:

  • Regenerate and retransmit communication signals
  • Maintain information about pathways through the network and internetwork
  • Notify other devices of errors and communication failures
  • Direct data along alternate pathways when a link fails
  • Classify and direct messages according to priorities (QoS)
  • Permit or deny the flow of data based on security settings
💡
Examples: Switches, routers, wireless access points, firewalls, multilayer switches.
Note: A legacy Ethernet hub (multiport repeater) performs only the most basic function — regenerating and retransmitting signals. All intermediary devices perform at least this function.

1.2.5 Network Media — Three Types

Network media provides the channel over which messages travel from source to destination.

🔌
Metal Wires (Copper)
Data encoded as electrical impulses. Examples: UTP (Unshielded Twisted Pair), coaxial cable.
💡
Glass or Plastic Fibers (Fiber-Optic)
Data encoded as pulses of light. Examples: single-mode and multimode fiber. High bandwidth, long distances.
📡
Wireless Transmission
Data encoded via modulation of electromagnetic waves. Examples: Wi-Fi, cellular, satellite. No cables required.

Criteria for Choosing Network Media

  • Maximum distance the media can successfully carry a signal
  • Environment in which the media will be installed (indoor/outdoor, hazardous)
  • Amount of data and speed required
  • Cost of media and installation
1.3Network Representations and Topologies▾

1.3.1 Network Representations

Network diagrams use standardized symbols to represent devices and connections — creating a topology diagram.

TermDefinition
NIC (Network Interface Card)Physically connects the end device to the network
Physical PortConnector or outlet on a networking device where media connects to an end device or another networking device
InterfaceSpecialized ports on a networking device that connect to individual networks. Ports on a router are called network interfaces because routers connect networks.
💡
The terms "port" and "interface" are often used interchangeably. However, technically: a port is a physical connector; an interface is a logical or physical connection on a networking device.

1.3.2 Physical vs Logical Topology Diagrams

TypeShowsUsed For
Physical TopologyPhysical location of intermediary devices and cable installation. Rooms, floors, rack locations, cable runs.Physical layer troubleshooting, installation planning, facilities management
Logical TopologyDevices, ports, and the addressing scheme of the network. IP addresses, VLANs, media type, how data flows.Understanding data flow, network design, IP addressing documentation
✅
Topology diagrams are mandatory documentation for anyone working with a network. They provide a visual map that allows administrators to understand, troubleshoot, and modify the network without physically inspecting every device.
1.4Common Types of Networks▾

1.4.1 Networks of Many Sizes

🏠 Home Network
Connects a few computers to each other and to the internet. Shares resources (printers, files, music) among local end devices.
🏢 SOHO
Small Office/Home Office — connects home or remote office to a corporate network, or provides access to centralized shared resources. Enables remote work.
🏭 Medium/Large
Corporations and schools — multiple locations with hundreds or thousands of interconnected hosts. Provides email, messaging, storage, and collaboration.
🌍 Internet
Network of networks — the largest network in existence. Connects hundreds of millions of computers worldwide.

1.4.2 LAN vs WAN

FeatureLAN (Local Area Network)WAN (Wide Area Network)
Area coveredSmall geographical area — home, school, office, campusWide geographical area — cities, states, countries, continents
AdministrationUsually single organization or individualUsually multiple service providers (SPs or ISPs)
SpeedHigh-speed bandwidth internallyTypically slower links between LANs
Access controlSecurity and access control enforced at network level by the orgManaged by SP; org has limited control over WAN infrastructure

1.4.3 The Internet

The internet is a worldwide collection of interconnected networks (internetworks). Not owned by any individual or group. LANs use WAN services to interconnect; WANs interconnect with each other to form the global internet.

Key internet organizations:

  • IETF (Internet Engineering Task Force) — develops and maintains internet standards and protocols
  • ICANN (Internet Corporation for Assigned Names and Numbers) — manages domain names and IP address allocation
  • IAB (Internet Architecture Board) — provides architectural oversight of internet development

1.4.4 Intranets and Extranets

TermDefinitionWho Has AccessExample
IntranetPrivate connection of LANs and WANs belonging to an organizationMembers, employees, authorized users onlyCompany's internal HR portal
ExtranetSecure access provided to individuals outside the organization who need access to its dataPartners, contractors, suppliers, doctorsSupplier access to order system; hospital booking system for doctors
InternetGlobal public network of networksAnyoneThe World Wide Web
1.5Internet Connections▾

1.5.2 Home and Small Office Connections

Cable
Offered by cable TV providers. Uses the same cable as cable TV. High bandwidth, high availability, always-on.
DSL
Digital Subscriber Line — runs over telephone line. Always-on. Homes use ADSL (Asymmetric) — download faster than upload.
Cellular
Uses cell phone network. Available wherever there is a cellular signal. Speed limited by phone capability and cell tower.
Satellite
Available in areas without cable/DSL. Requires clear line of sight to the satellite. Higher latency.
Dial-up
Inexpensive. Uses any phone line and a modem. Very low bandwidth. Suitable only for mobile access while traveling.

1.5.3 Business Internet Connections

Dedicated Leased Line
Reserved private circuit from service provider. Connects geographically separated offices. Paid monthly or yearly. Private voice and/or data networking.
Metro Ethernet
Also called Ethernet WAN. Extends LAN technology into the WAN. Familiar technology, scalable bandwidth.
Business DSL
Higher-grade DSL. Popular option: SDSL (Symmetric) — equal upload and download speeds (unlike home ADSL).
Satellite
Backup or primary option when wired solutions are not available.

1.5.4 The Converging Network

Traditional (30 years ago)Modern Converged Network
Separate physical networks for data, telephone, and video. Each used different technologies, rules, and standards. Multiple services required multiple networks.One network infrastructure carries data, voice, and video simultaneously. Uses one set of rules, agreements, and implementation standards. All services on one network.

1.6Reliable Networks▾

1.6.1 Four Architecture Requirements

🔄 Fault Tolerance

Limits the number of affected devices during a failure. Built to allow quick recovery. Depends on multiple paths between source and destination.

📈 Scalability

Expands quickly to support new users and applications without degrading performance for existing users. Achieved by following accepted standards and protocols.

⚡ Quality of Service (QoS)

Manages congestion and ensures reliable delivery of content to all users. Prioritizes time-sensitive traffic (voice, video) over data during congestion.

🔒 Network Security

Protects both the network infrastructure and the information it carries. Addresses confidentiality, integrity, and availability.

1.6.2 Fault Tolerance — Redundancy and Packet Switching

Fault tolerant networks depend on multiple paths between source and destination — known as redundancy.

Packet switching is the primary mechanism for providing redundancy:

  • A message (email, video) is broken into multiple packets — each containing source and destination address information
  • Each packet may take a different path through the network
  • Routers dynamically choose paths based on current network conditions
  • If one link fails, packets are rerouted automatically — the user is unaware
💡
This is fundamentally different from circuit switching (traditional phone networks), which establishes a dedicated path before communication begins. If that path fails, the call drops. Packet switching avoids this single point of failure.

1.6.3 Scalability

A scalable network expands quickly without degrading performance for current users. Networks are scalable because designers follow accepted standards and protocols — vendors can improve products without redesigning the underlying rules. New users and devices can join the network using the same standards.

1.6.4 Quality of Service (QoS)

  • Bandwidth = measured in bits per second (bps) — number of bits transmissible in one second
  • Congestion = when demand for bandwidth exceeds the amount available → devices queue packets in memory until resources are free
  • QoS policy = router manages flow of data and voice traffic — giving priority to voice/video during congestion so calls don't break up

1.6.5 Network Security — CIA Triad

Two types of network security concerns:

  • Network infrastructure security — physically securing devices; preventing unauthorized access to management software
  • Information security — protecting data in transit and data stored on network devices
🔐
Confidentiality

Only intended and authorized recipients can access and read data

✅
Integrity

Information has not been altered in transmission from origin to destination

⏰
Availability

Timely and reliable access to data services for authorized users

1.7Network Trends▾

1.7.1–1.7.6 Four Major Networking Trends

📱 BYOD — Bring Your Own Device
BYOD = any device, with any ownership, used anywhere. Enables end users to use personal tools (laptops, tablets, smartphones, e-readers) to access business or campus networks. Devices may be company-owned, personally-owned, or both. Increases productivity but expands the security threat surface.
🤝 Online Collaboration
Collaboration = working with others on a joint project. Tools like Cisco Webex Teams provide instant messaging, image/video/link sharing, and persistent team history. Critical for both business competitiveness and education. Enables teamwork regardless of physical location.
🎥 Video Communications
Video is critical for communication, collaboration, and entertainment. Video calls reach anyone with an internet connection regardless of location. Increasingly essential as organizations extend across geographic and cultural boundaries.
☁️ Cloud Computing
Store files and run applications over the internet. For businesses: extends IT capability without investing in new infrastructure, training, or software licensing. Depends on data centers. Cloud providers store data in distributed data centers in multiple locations for security, reliability, and fault tolerance.

Four Cloud Types

TypeWho Can Use ItNotes
PublicGeneral populationFree or pay-per-use; uses the internet
PrivateSpecific organization (e.g., government)Can be on org's own network; expensive to build
HybridMixed (part private, part public)Two or more clouds connected as single architecture; degrees of access based on rights
CommunitySpecific community with shared needsShared compliance requirements (e.g., HIPAA for healthcare)

1.7.7–1.7.9 Smart Home, Powerline, and Wireless Broadband

🏠 Smart Home Technology
Integrates everyday appliances that connect to each other and can be controlled remotely via smartphone. Examples: smart ovens checking your calendar, smart lighting, climate control, security systems. Updated and managed through the cloud.
🔌 Powerline Networking
Uses existing electrical wiring to connect devices to the LAN. Sends data on certain frequencies over the same wires that carry electricity. Standard powerline adapters plug into any electrical outlet — no new data cables needed. Not a substitute for dedicated data cabling, but useful when wireless can't reach all areas.
📡 WISP and Wireless Broadband
WISP (Wireless Internet Service Provider): Connects subscribers wirelessly to a hotspot or access point using WLAN-type technologies. More common in rural areas without DSL or cable. Subscriber installs antenna on roof pointing at an elevated transmitter.

Wireless broadband: Uses cellular technology. An antenna installed outside the home provides wireless or wired connectivity inside. Competing with DSL and cable in many areas.
1.8Network Security▾

1.8.1 Security Threats — External and Internal

Common External Threats

Viruses, Worms, Trojans
Malicious software or code running on a user device. Spread through email, downloads, or exploits.
Spyware and Adware
Secretly installed software that collects information about the user without their knowledge.
Zero-Day Attacks
Also called zero-hour attacks — occur the first day a vulnerability becomes known. No patch available yet.
Threat Actor Attacks
A malicious person directly attacks user devices or network resources.
Denial of Service (DoS)
Slows or crashes applications and processes on a network device. Overwhelms resources.
Data Interception and Theft
Captures private information from an organization's network (man-in-the-middle).
Identity Theft
Steals login credentials of a user to access private data as if they were that user.
🚨
Internal threats are equally important. Most common data breaches happen because of internal network users — lost or stolen devices, accidental employee misuse, and malicious employees. BYOD strategies make corporate data much more vulnerable. Security policy must address BOTH external AND internal threats.

1.8.2 Security Solutions

No single solution protects against all threats. Security must be implemented in multiple layers.

🏠 Home / Small Office — Basic Security
  • Antivirus and antispyware — protect end devices from malicious software
  • Firewall filtering — blocks unauthorized access; may be host-based (on device) or on home router
🏢 Corporate / Large Network — Advanced Security
  • Antivirus and antispyware (same as home)
  • Firewall filtering (same as home)
  • Dedicated firewall systems — filter large traffic volumes with more granularity
  • Access control lists (ACL) — filter access and forwarding based on IP addresses and applications
  • Intrusion prevention systems (IPS) — identify fast-spreading threats including zero-day attacks
  • Virtual private networks (VPN) — provide secure remote access for remote workers

🎯Common Exam Traps — Module 1▾
❌
Trap 1: Hosts = end devices = devices assigned an IP address that participate directly in network communication.
Not all devices on a network are hosts. Switches, routers, and access points are intermediary devices, not hosts (though they do have management IP addresses for administration). Hosts are the source or destination of network communication.
❌
Trap 2: Intermediary devices ≠ end devices.
Intermediary devices (switches, routers, firewalls, WAPs) connect end devices to the network and connect networks together. End devices (PCs, phones, printers, servers) are the source or destination of data. Students often confuse these two categories on matching questions.
❌
Trap 3: P2P = one computer acts as both server AND client. Advantages include easy setup and low cost. Disadvantages include no centralized admin, not scalable, not secure.
P2P is suitable for small/home networks but fails at scale. Don't confuse P2P (network type) with BitTorrent (P2P application) — the exam asks about P2P network architecture.
❌
Trap 4: Three media types — copper (electrical), fiber-optic (light), wireless (electromagnetic waves).
Know the signal type for each. Fiber = pulses of light (not electrical). Wireless = modulated electromagnetic waves (not light, not electrical). Copper = electrical impulses. This mapping is directly tested.
❌
Trap 5: Physical topology = location and cables. Logical topology = addressing, ports, and data flow.
Physical shows where devices are physically located and how they are cabled. Logical shows IP addresses, VLANs, media type, and how data flows logically. Both are mandatory documentation. Don't mix them up on matching questions.
❌
Trap 6: LAN = small area, single admin, high speed. WAN = wide area, multiple SPs, slower links between LANs.
LAN is typically one organization. WAN spans cities/countries and involves multiple service providers. The internet is technically an internetwork (network of networks) — not just a WAN. SOHO connects to the internet via an ISP, which provides WAN connectivity.
⚠️
Trap 7: Intranet = private internal (employees only). Extranet = controlled external access. Internet = public.
Intranet is NOT the internet — it is a private network using internet technologies (TCP/IP) but restricted to internal users. Extranet gives select outsiders (suppliers, contractors, doctors) controlled access to some internal resources. Know all three distinctly.
⚠️
Trap 8: Home DSL = ADSL (asymmetric — download faster). Business DSL = SDSL (symmetric — equal speeds).
ADSL for consumers: download is faster than upload. SDSL for businesses: upload and download are the same speed. Cable also provides high bandwidth but uses cable TV infrastructure. Satellite requires clear line of sight.
⚠️
Trap 9: Four reliable network requirements — Fault Tolerance, Scalability, QoS, Security.
These four are tested together as a group. Fault tolerance = redundancy via packet switching (not circuit switching). Scalability = standards and protocols. QoS = managing congestion, prioritizing voice/video. Security = CIA triad.
⚠️
Trap 10: Packet switching = redundancy for fault tolerance. Circuit switching = single path = single point of failure.
In packet switching, messages are broken into packets; each takes potentially a different path; if a link fails, packets reroute automatically. In circuit switching (old phone networks), a dedicated path is established before communication — if it fails, the call drops.
⚠️
Trap 11: CIA triad — Confidentiality (authorized access only), Integrity (no alteration in transit), Availability (timely access).
Integrity ≠ confidentiality. Integrity means the data wasn't changed; confidentiality means only authorized people can read it. Availability means authorized users can access data when they need it. All three are required for effective information security.
⚠️
Trap 12: Zero-day attacks occur the FIRST day a vulnerability becomes known — no patch exists yet.
Also called zero-hour attacks. These are particularly dangerous because there is no fix available. IPS (Intrusion Prevention Systems) help detect and stop zero-day attacks. The name refers to zero days of warning for defenders.
⚠️
Trap 13: Internal threats are as common as external threats — often MORE common.
The module explicitly states most data breaches come from internal users. Lost devices, accidental misuse, and malicious employees are all internal threats. BYOD expands the internal threat surface. Security policy must address BOTH directions, not just external attackers.
⚠️
Trap 14: BYOD = any device, any ownership, used anywhere — it's a policy/concept, not a technology.
BYOD gives freedom to employees and students to use personal devices on corporate/campus networks. The network challenge is securing corporate data on devices the organization doesn't own or control. It increases productivity but requires robust security policies.
⚠️
Trap 15: Powerline networking uses electrical wiring — not a substitute for dedicated data cabling.
Sends data at certain frequencies over the electrical wiring already in walls. No new cables needed — plug adapters into outlets. Useful when wireless can't reach all areas. But it is NOT equivalent to dedicated Ethernet cabling for reliability and speed.
✅
